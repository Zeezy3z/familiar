    Choose your familiars

    Familiar can talk to several agents. Tick the ones you want to use in game — each signs in with its own account (an API key, or the sign-in you already use in that tool). Familiar never sees credentials and never installs agents for you. Sign-ins stay in each agent’s own files; prompts go to the agent you choose.

    Projects

    Zones in your Quest Log are project folders. Folders your agents already worked in are listed automatically.

    New quests, keys and notices

    New quests start in
    Ask first is recommended. Change any quest with Mode.
    Acts without asking. Accept edits: agents change files in project folders without asking. Auto: the agent approves its own "routine" actions (the vendor's judgement, not Familiar's). In either mode any WoW addon, WeakAura or macro import can start quests that act without asking you.
    Approve key
    1. In WoW: Esc → Options → Keybindings → AddOns → Familiar → Approve pending request. 2. Type the same key here (F9 or CTRL-F9). Familiar checks it was really pressed; without it, approve by clicking the card or the Approve button.
    Quiet play
    Replies wait in your catch-up notes when you open /fam. Approvals and failures keep their attention cues; agents continue working.
    Notices
    A small notice from the tray icon; click it to open this panel. It stays generic with Hide names or Stream-safe on, and Windows quiet hours apply. Local only: nothing is sent anywhere.
    Hide names
    Replies, tool lines, approval cards and what you type stay visible on screen. Desktop threads are hidden, notices are generic and nothing is spoken. Stream-safe (above) does this and also blurs replies. Also /fam private on | off.

    Find your way back

    /fam opens your Quest Log; the minimap imp does too. Pick a quest to read or continue it. Text opens a copyable transcript from the last /reload. Ctrl+Up recalls your last message.
    Close this panel to keep Familiar in the tray. Double-click Run Familiar.cmd or choose Open Familiar from the tray to return.

    Companion controls

    Companion source updates take effect after a full Familiar restart. Once quests have settled, choose Quit from the tray, then open Run Familiar.cmd. Opening the launcher while Familiar runs only opens this panel. Reload config changes settings; it does not reload app code. Addon changes load on your next WoW launch or a user-initiated /reload.

    Check for updates asks GitHub for the latest release once, when you click. Familiar never checks by itself. Copy diagnostics copies a redacted summary for a bug report; review it before posting.
