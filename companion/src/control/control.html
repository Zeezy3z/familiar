    Safety

    Mode
    Ask first is recommended. Modes are changed here, not in the game.
    Acts without asking. Accept edits: agents change files in project folders without asking. Auto: the agent approves its own "routine" actions (the vendor's judgement, not Familiar's). In either mode any WoW addon, WeakAura or macro import can start quests that act without asking you.
    Approve key
    Bind “Approve the pending request” in WoW (Esc → Options → Keybindings → AddOns → Familiar), then choose Set key and press the same key here.
    Off by default: another addon could place a request where you are about to click. With this off, approve with your Approve key or here.
    Off by default: allow rules, hooks and MCP servers from your own Claude or Codex settings would apply to quests started in game. Project instructions (CLAUDE.md) are always read.
